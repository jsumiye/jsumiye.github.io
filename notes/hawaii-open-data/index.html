Making Hawaii open data feel searchable

2024 · HACC finalist

Hawaii publishes a lot of datasets. Finding a useful one still felt like wandering a filing cabinet. For the 2024 Hawaii Annual Code Challenge we built a frontend that can search, filter, bookmark, and chart those catalogs. We were finalists. This was also the first time I shipped software with a team on GitHub instead of with myself.

Live site: ool-frontend.vercel.app.

What I actually owned

I was a frontend developer on the team. The list is specific because group projects love to turn into "we all did everything."

  • Search across datasets
  • Sort and filter
  • Dataset cards. Title, description, tags
  • Bookmarks in localStorage
  • Recently opened datasets
  • An info tab for the dataset you have open
  • Downloading a chart as an image
  • Help copy and tooltips

Bookmarks in localStorage is not glamorous. It is the difference between "I will remember this CSV" and actually finding it again on a library computer that will forget you at 5 p.m. 

function toggleBookmark(id) {
  const key = "ood.bookmarks";
  const current = JSON.parse(localStorage.getItem(key) || "[]");
  const next = current.includes(id)
    ? current.filter((item) => item !== id)
    : [...current, id];
  localStorage.setItem(key, JSON.stringify(next));
  return next;
}

A table is a start. A graph is why you stayed

Once you pick a dataset, you need to see it. The table is the honest view. The graph is the one you download for a slide. I wired the download so a chart left the browser as an image instead of a screenshot with the browser chrome still on it.

A chat box on government CSVs

We pointed OpenAI at dataset suggestions and user questions. It is useful when it names a dataset you would not have queried. It is wrong when it sounds sure. I still want the catalog, the filters, and the table to work if the model is having a day.

GitHub, finally

I knew commits. I did not know a pull request that someone else would reject. Branch names, merge conflicts, a review that says the card padding is wrong. That was the other half of HACC for me. Tailwind and shadcn/ui made the UI hold together. Axios talked to the API. Environment variables kept keys out of the repo, which is the kind of sentence you only write after you almost committed one.

If I opened the repo tomorrow I would still look at search first. A data explorer that cannot find "Maui" is just a pretty empty state.
