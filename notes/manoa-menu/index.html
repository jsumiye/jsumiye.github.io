Campus Center's menu, scraped and translated

2024

International students at UH Mānoa should not have to guess what "plate lunch" means from a PDF. Manoa Menu pulls dining hall menus, translates them, and puts locations on a map. I built the menu page end to end and the dining locations page. I also ran the weekly meeting, which is a different kind of parsing.

There is no menu API

Campus Center publishes HTML. Hale Aloha publishes a weekly PDF. I used jsdom on the first and pdf-parse on the second, then stored a versioned snapshot so the UI is not scraping on every page load. 

export async function getCampusCenterMenu() {
  const html = await fetch(CAMPUS_CENTER_URL).then((r) => r.text());
  const dom = new JSDOM(html);
  const days = [...dom.window.document.querySelectorAll(".menu-day")];

  return days.map((day) => ({
    label: day.querySelector("h2")?.textContent?.trim(),
    plate: textList(day, ".plate-lunch li"),
    grab: textList(day, ".grab-and-go li"),
  }));
}

The selectors in that snippet are the idea, not a contract with the university's CMS. The CMS will move a class name. The job is to notice before Monday lunch.

API routes compare the newly fetched menu to the stored one. If nothing changed, we keep the last translation. OpenAI is billed per token. Re-translating "Chicken Katsu" every ten minutes is a hobby I declined.

English first, then Japanese

The menu UI is a week of plate lunch and grab-and-go. Language is a control, not a separate site. I wrote prompts that asked for JSON, because a paragraph of Japanese with no structure is how you ship "Monday" under Friday.

Hours are a map problem

The locations page embeds Google Maps and a directions button that opens the phone's own maps app. Students already have a maps app. I do not need to invent a worse one.

The rest of the stack, and the meetings

Next.js API routes, Prisma against Postgres, Playwright for end-to-end tests, ESLint, Vercel. I learned the Vercel CLI by reading error logs at hours I will not defend. Material UI showed up on some pages. Bootstrap on others. A semester project is allowed to be a little inconsistent if the menu is right.

I coordinated tasks, reviewed code, and kept a weekly agenda. The technical lesson is scraping. The other lesson is that a menu app dies if nobody notices the PDF layout changed on Sunday night.
