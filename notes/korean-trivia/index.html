Culture trivia for a university language program

2024

Trivia for the Korean Language Flagship Center's Culture Day. Sixteen questions on language, food, history, and pop culture. The production build is served from the program site, under /trivia, and has passed 150 plays. React and Vite. Material UI for the card and buttons.

Event use

There is no account and no save. A visitor starts, finishes, and taps Restart for the person behind them. The Flagship logo stays at the top of the viewport and links to the program homepage. A campus photo is blurred behind the card so the page still reads as the center's site rather than a separate app.

Answer reveal

Submit requires a choice. The option list then leaves the card, and a correct or incorrect panel takes its place, with the right answer shown. Next Question is a separate control, so the reveal is not skipped on the way to the score. True or false items render two rows. Four-choice items render four. Progress is written on the prompt as n of 16.
